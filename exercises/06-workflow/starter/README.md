# 第 6 课作业：亲手写两种工作流

工作流 = **步骤由我们的代码定好**，模型只负责其中某几步。打开 `workflow.py`，把标了 `TODO` 的函数写出来。

这份作业用的是**假的大模型**（`fake_llm.py`）：`llm.ask(提示词)` 返回一段文字，按写好的剧本一句句回复，不联网、不花钱。
提示词怎么写由你决定，检查脚本只看提示词里有没有带上必要的信息。

## 基础要求

### 1. 提示链 + 检查关卡：`write_and_translate(llm, product, keyword, max_len=50)`
给商品写一句中文广告文案，合格了再翻译成英文：
1. 问模型一次，让它给 `product` 写中文文案。提示词里要带上 `product` 和 `keyword`（要求文案里包含这个词）
2. **检查关卡**（用普通代码检查，不问模型）：文案（去掉首尾空白后）不超过 `max_len` 个字，并且包含 `keyword`
3. 不合格：**不要再问模型**，直接返回 `{"ok": False, "copy": 文案, "reason": 原因}`
   - 太长时，`reason` 里要有「太长」两个字
   - 缺关键词时，`reason` 里要写出缺的那个关键词
4. 合格：再问模型一次，让它把文案翻译成英文（提示词里要带上文案），返回 `{"ok": True, "copy": 文案, "english": 英文}`

### 2. 路由：`route(llm, question, handlers, default)`
先分类，再交给对应的处理函数：
- `handlers` 是一个字典，如 `{"退款": 处理退款的函数, "技术问题": 处理技术问题的函数}`
- 问模型一次，让它判断 `question` 属于哪一类、只回答类别名。提示词里要带上 `question` 和**所有类别名**
- 模型的回答可能带空格或换行，先去掉首尾空白
- 类别在 `handlers` 里：调用 `handlers[类别](question)`，返回它的结果
- 类别不认识（**默认分支**）：调用 `default(question)`，返回它的结果

## 进阶要求（进阶档）

### 3. 评估者-优化者：`evaluate_optimize(llm, task, max_rounds=3)`
写 → 评 → 按意见改，循环：
1. 问模型，按 `task` 写一版初稿（提示词里带上 `task`）
2. 再问模型，评价这一版（提示词里带上这一版的内容）。模型的回答**以「通过」开头**就算通过，否则整段回答就是修改意见
3. 通过了：返回 `{"result": 这一版, "rounds": 一共写了几版}`
4. 没通过、而且已经写了 `max_rounds` 版：不再修改，返回最后一版和版数
5. 没通过、还没到上限：问模型按意见改一版（提示词里要带上上一版和修改意见），回到第 2 步

## 怎么检查

- 自己跑跑看：`python3 demo.py`，会打印出每次问模型的提示词和回答
- 写完告诉导师「写好了」，导师会运行检查脚本告诉你哪些通过了
