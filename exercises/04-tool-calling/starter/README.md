# 第 4 课作业：给 Agent 做一个「查天气」工具

工具 = **说明书**（给模型看，模型靠它决定要不要调用、传什么参数） + **执行函数**（我们的代码真正去做）。
这份作业两样都要你来写。打开 `tools.py`，把标了 `TODO` 的地方补上。

## 基础要求

1. **写说明书 `TOOLS`**：补全 `get_weather` 工具的说明书
   - `description` 写清楚：这个工具做什么、什么时候该用（至少 10 个字）
   - 参数 `city`（城市名，字符串），必填
2. **写执行函数 `run_tool(name, arguments)`**
   - `name` 是模型想调用的工具名，`arguments` 是模型给的参数，**是一段 JSON 文本**（如 `'{"city": "北京"}'`），要先用 `json.loads` 转成字典
   - 返回交回给模型的文字（字符串）
3. **出错时不要让程序崩掉**，而是返回一段说明，告诉模型错在哪、该怎么改。模型看到说明，下一步就能自己改正：
   - 查不到的城市：说明里要列出支持哪些城市
   - 不认识的工具名：说明里要写出有哪些工具可用
   - 参数不是合法的 JSON，或者缺了 `city`：说明里要提到 `city`

## 进阶要求（进阶档）

4. 给 `get_weather` 加一个**可选**参数 `days`（整数，查未来几天，1~3，不填就是 1）
   - 说明书里写上它的类型和范围（`minimum`、`maximum`），不要放进 `required`
   - `days=2` 时，返回两天的天气（`get_weather` 函数已经支持）
   - `days` 超出 1~3 时，返回说明，里面要写出允许的范围「1~3」
