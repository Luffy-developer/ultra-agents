# 第 8 课作业：亲手写一个迷你知识库

RAG 的四步：**切块 → 向量化 → 检索 → 生成**。这份作业你来写其中最关键的「切块」和「检索」，进阶档再写「拼 Prompt」。
打开 `rag.py`，把标了 `TODO` 的地方补上。知识库用的是 `knowledge.md`（一份假的员工手册）。

> 真实项目里，「向量化」要调用 Embedding 模型，把文字变成一串数字再比较。
> 为了不花钱、不联网，这份作业用一个简单的 `similarity` 函数代替：它数一数问题里的「两个字的词组」有多少也出现在这块资料里。
> 这个函数已经写好了，直接用就行。原理和向量检索一样：**越像，分数越高**。

## 基础要求

1. **切块 `chunk(text, size, overlap)`**：把一段文字按长度切成一块一块
   - 每块最多 `size` 个字
   - 相邻两块要**重叠** `overlap` 个字：后一块的开头，就是前一块的最后 `overlap` 个字
   - 切到文字结尾就停，不要多出一块只有重叠部分的
   - 文字不超过 `size` 个字时，整段就是一块；空文字返回空列表 `[]`
   - `overlap` 大于等于 `size` 时没法往前切，抛出 `ValueError`
2. **检索 `search(chunks, query, k)`**：从所有块里找出和问题最相关的 `k` 块
   - 用 `similarity(query, 块)` 给每块打分
   - 返回分数最高的 `k` 块（列表，里面是块的文字），**分数高的排在前面**
   - 块的数量不到 `k` 时，有几块返回几块

## 进阶要求（进阶档）

3. **相关度门槛**：给 `search` 加一个参数 `min_score`（默认 `0`），分数**低于** `min_score` 的块不要返回。
   全都低于门槛时返回空列表——调用方看到空列表，就可以直接回答"资料里没有"，连模型都不用调
4. **拼 Prompt `build_prompt(question, chunks)`**：把检索到的块和问题拼成一段发给模型的 Prompt，里面要有：
   - 每块资料前面标上编号：第一块前面写 `[1]`，第二块写 `[2]`……
   - 用户的问题原文
   - 要求模型只根据资料回答，回答时标出**引用**了哪几条资料的编号
   - 要求模型：资料里找不到答案时，就回答「资料里没有」（这五个字原样写进 Prompt）

## 怎么检查

- 自己跑跑看：`python3 try_it.py`，会打印切出来的块、检索结果和拼好的 Prompt
- 写完告诉导师「写好了」，导师会运行检查脚本告诉你哪些通过了
