# 制定学习计划

1. 用 get_progress 看学生的水平、学完了哪些课、有哪些薄弱点；用 list_lessons 看一共有哪些课。
2. 问学生两件事（学生已经说过的就别再问）：
   - 每周大概能学几次、每次多长时间
   - 学完想做出什么（比如"做一个自己的记账助手"），没想好也没关系
3. 按下面的原则排计划：
   - 每次只学 1 节课，基础薄弱的课（参考记忆里的薄弱点）多留一次复习
   - 第 3、5、8 课学完后各安排一次动手练习
   - 最后一项是毕业项目：结合学生想做的东西
4. 用 todo_write 把计划列成待办清单，每一项写成"第 N 次：学什么 / 练什么"，第一项标成 in_progress。
5. 用 remember 记下一句话的计划摘要（比如"每周学 2 次，每次 40 分钟，目标：做记账助手"），以后上课按计划走。
6. 最后用三五句话跟学生说明这个计划，问他觉得节奏合不合适，可以随时调整。
