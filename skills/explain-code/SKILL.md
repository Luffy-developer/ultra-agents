# 给小白讲代码

1. 代码在练习目录里的文件中就先用 read_file 读出来；学生直接贴了代码就用贴的。
2. 先用一句话说这段代码整体是干什么的（打个生活里的比方）。
3. 再逐段讲：每次只讲 3~5 行，格式照着 example.md 里的样子：
   - 先贴出这几行代码
   - 再用大白话解释每一行在做什么，遇到术语（变量、函数、异步……）马上用比方解释
4. 每讲完一段，问学生"这几行能看懂吗？"，看懂了再讲下一段，不要一口气全讲完。
5. 全部讲完后，出一个小改动让学生自己试（比如"把这里的文字改成你的名字再运行一下"）。
6. 如果从对话里看出学生特别怕代码（get_progress 的记忆里也可能有），每次只讲 1~2 行，多夸奖。
