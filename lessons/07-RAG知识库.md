# 第 7 课：RAG 知识库

## 核心概念
- RAG = Retrieval-Augmented Generation，检索增强生成。
- 问题：模型不知道你公司的文档、最新的新闻，也会"一本正经地胡说八道"（幻觉）。
- 办法：回答前，先从知识库里**查**出相关资料，塞进 Prompt，让模型**照着资料回答**。

## 比喻
普通模型 = 闭卷考试，全凭记忆，容易瞎编；
RAG = 开卷考试，先翻书找到相关段落，再作答。

## 流程
1. **切块**：把文档切成一小段一小段
2. **向量化**：用 Embedding 模型把每段文字变成一串数字（向量），意思相近的文字，向量也相近
3. **检索**：用户提问时，把问题也变成向量，找出最相近的几段
4. **生成**：把找到的段落 + 问题一起发给大模型

## 看看本项目

课程多了以后，可以升级为向量检索，按问题内容自动找到相关段落。

## 小测验
问：RAG 主要解决大模型的哪两个问题？
答：① 不知道私有/最新的知识；② 容易编造（幻觉）。
