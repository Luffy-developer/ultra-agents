# 第 5 课：Agent 循环

## 核心概念
- **Agent = 大模型 + 工具 + 循环 + 记忆**
- 循环：模型调用工具 → 拿到结果 → 再思考 → 可能再调用工具……直到它觉得可以回答了。
- 这就是 Agent 和普通聊天机器人的区别：它能**自己决定下一步做什么**，连续完成多步任务。

## 伪代码
```
messages = [system, user]
重复最多 N 次:
    回复 = 模型(messages, tools)
    if 回复没有调用工具:
        输出回复; 结束
    for 每个工具调用:
        结果 = 执行工具
        messages.append(结果)
```

## 动手练习
打开 agent-tutor 源码里的 `src/agent.ts`，找到 `runTurn` 函数里的 `for` 循环，对照上面的伪代码读懂它。
你正在使用的这个导师，就是这样运作的！你看到的「🔧」提示，就是循环里的一次工具调用。

## 小测验
问：如果模型一直调用工具、永远不停，会发生什么？该如何防范？
参考：会无限循环、消耗费用。可以设置最大循环次数（比如 10 次）。
