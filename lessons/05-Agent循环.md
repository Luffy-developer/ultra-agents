# 第 5 课：Agent 循环

## 核心概念
- **Agent = 大模型 + 工具 + 循环 + 记忆**
- 循环：模型调用工具 → 拿到结果 → 再思考 → 可能再调用工具……直到它觉得可以回答了。
- 这就是 Agent 和普通聊天机器人的区别：它能**自己决定下一步做什么**，连续完成多步任务。

## 伪代码
```
messages = [system, user]
重复最多 N 次:
    回复 = 模型(messages, tools)
    if 回复没有调用工具:
        输出回复; 结束
    for 每个工具调用:
        结果 = 执行工具
        messages.append(结果)
```

## 动手练习
打开 agent-tutor 源码里的 `src/agent.ts`，找到 `runTurn` 函数里的 `for` 循环，对照上面的伪代码读懂它。
你正在使用的这个导师，就是这样运作的！你看到的「⎿ [tools]…」提示，就是循环里的一次工具调用。

## 进阶：先规划再动手
任务一长，模型容易做着做着忘了还剩哪几步。解决办法和人一样：**先列清单，做一项勾一项**。
- 本项目给导师准备了一个 `todo_write` 工具（`src/todo.ts`）：要做 3 步以上的任务时，导师先列出待办清单，
  开始做某一步就标成「进行中」，做完标成「已完成」。终端里的「⎿ [todo]待办清单」就是它，随时输入 `/todos` 也能查看
- 有意思的是，这个工具**什么实际的事都不做**，只是把清单记下来、显示出来。
  但模型每次更新清单时，都等于把"已经做完什么、接下来做什么"重新想了一遍——这就是**规划**
- Claude Code 的 Todo 列表也是一样的原理

## 小测验
问：如果模型一直调用工具、永远不停，会发生什么？该如何防范？
参考：会无限循环、消耗费用。可以设置最大循环次数（比如 10 次）。
