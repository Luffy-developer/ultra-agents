# 第 1 课：大模型是什么

> **学完你能**：用自己的话说清大模型是怎么"说话"的；解释为什么它记不住你、不能上网、有时会一本正经地胡说；分清"推理模型"和"让模型一步步想"。

## 基础

### 1. 一个读过海量书的"超级接话王"
- 大语言模型（LLM）做的事情其实只有一件：**你给它一段文字，它预测接下来最可能出现的文字**，一小段一小段地往下接，直到接完一整段回答。
- 它之所以显得"懂"很多，是因为训练时读过海量的书、网页和代码，见过无数种"上一句怎么接下一句"。
- 比喻：你说"床前明月光"，它接"疑是地上霜"——不是它查了唐诗，而是它见过太多次，知道这样接最顺。

### 2. 它没有记忆，也不能上网、不能动手
- **没有记忆**：每次调用都是全新的。聊天软件看起来"记得"你之前说的话，是因为程序每次都把之前的对话历史一起发给了它（第 3 课「用代码调用 API」会亲手写）。
- **不能上网、不能动手**：它只会输出文字。想让它查天气、写文件，需要我们给它"工具"（第 4 课「工具调用」）。
- 比喻：大模型 = 一个很聪明但被关在房间里的顾问。你从门缝塞纸条进去，它写回答塞出来。它看不到外面，也记不住上一张纸条，除非你把旧纸条一起塞进去。

### 3. token：模型读写文字的单位
- 模型不是一个字一个字地读，而是把文字切成一小块一小块，叫 **token**。一个 token 可能是一个汉字、半个词，或一个英文单词的一部分。
- 为什么要关心 token：
  - **收费按 token 算**：你发过去的（输入）和它写出来的（输出）都要算钱
  - **一次能读的量有上限**：这个上限叫**上下文窗口**，好比顾问的桌面——桌子就这么大，纸条塞太多就放不下了
- 看看本项目：导师每说完一轮，下面那行灰字就是这一轮用了多少 token；输入 `/cost` 能看总账。

### 4. 幻觉：一本正经地胡说
- 模型的本事是"接得顺"，不是"说得对"。遇到它没见过、记不清的事，它也会接出一段**听起来很像真的**的话——编出不存在的书名、网址、数字。这叫**幻觉**。
- 应对办法：让它照着资料回答（第 8 课「RAG 知识库」）、让它上网查（第 9 课「让 Agent 上网」）、重要的事自己核实。

### 5. 推理模型 vs 让模型"一步步想"
- **让模型一步步想（思维链，CoT）**：在问题后面加一句"请一步步思考"，模型会先写出推理过程再给答案，复杂问题更容易做对。这是**写 Prompt 的技巧**，任何模型都能用。
- **推理模型**（如 DeepSeek-R1、OpenAI o1）：是**专门训练过**、会先"想"再答的模型。它的思考过程和最终回答是分开的——有的模型把思考放在 `<think>` 和 `</think>` 之间（来自 Hugging Face Agents Course 第 1 单元）。
- 比喻：CoT 像考试时老师提醒你"把草稿写出来"；推理模型是一个从小就养成了先打草稿习惯的学生，不用提醒。
- 看看本项目：如果你用的是推理模型，导师回答前出现的灰底面板、最后那行"思考了 N 秒"，就是它的思考过程。`src/agent.ts` 里从 `reasoning_content`（DeepSeek 等用这个名字）读出思考内容，**只显示、不放进对话历史**。

## 进阶

### 1. 每一步都是"抽签"：采样与温度
- 模型每次接下一个 token 时，算出的是一张**概率表**（比如"霜"60%、"雪"20%……），再按概率抽一个。
- **温度（temperature）** 控制抽签的随机程度：温度低，几乎总选概率最高的，回答稳定、保守；温度高，更常选到不那么常见的词，回答更多样，也更容易跑偏。
- 做 Agent 时，判断、调用工具这类要求准确的步骤，一般用较低的温度；写文案、想点子可以高一些。

### 2. 为什么同样的问题，每次回答不一样
- 因为有抽签，同一个问题问两次，答案的措辞甚至结论都可能不同。
- 这对做 Agent 影响很大：**跑一次成功，不代表每次都成功**。所以改了 Prompt、换了模型之后，不能只试一两次凭感觉，要用一批测试题反复跑（第 13 课「评估与上线」）。

### 3. 上下文窗口和成本的关系
- 模型没有记忆，所以**每调用一次，都要把整段对话重新发一遍**。对话越长，每次的输入 token 越多，越慢也越贵。
- Agent 一轮里可能调用好几次工具，每次都要把越来越长的对话再发一遍——这是 Agent 比普通聊天贵得多的主要原因。
- 窗口塞得越满，模型也越容易"看漏"前面的内容。怎么只放最有用的内容进去，是第 7 课「记忆与上下文工程」的主题。
- **缓存**：和上一次开头相同的内容，很多服务商按便宜得多的价格收费。本项目的用量统计会单独算出「缓存」部分（`src/usage.ts`）。

## 常见误区
- ❌ "模型会记住我昨天跟它说的话" → ✅ 模型本身没有记忆，是程序把历史对话一起发过去的
- ❌ "模型说得这么肯定，一定是对的" → ✅ 模型擅长"说得顺"，不保证"说得对"，会出现幻觉
- ❌ "推理模型就是加了一句'请一步步思考'" → ✅ 那是 CoT 提示技巧；推理模型是专门训练出来、自带思考过程的
- ❌ "一个 token 就是一个字" → ✅ token 是模型切分文字的单位，不一定和字、词一一对应
- ❌ "这个 Prompt 我试了一次效果很好，就没问题了" → ✅ 模型的回答有随机性，要多试几次、用一批题来检验
