# 第 6 课：记忆（Memory）

## 核心概念
- 第 1 课说过：模型本身没有记忆。Agent 的"记忆"都是我们用代码帮它做的。
- **短期记忆**：就是 `messages` 列表——本次对话的全部历史。缺点是越聊越长，会超出模型的"上下文长度"，也越来越贵。
- **长期记忆**：把重要信息存到文件或数据库里，下次需要时用工具读回来。

## 比喻
短期记忆 = 你脑子里正在想的事（容量有限，聊完就忘）；
长期记忆 = 你的笔记本（写下来，下次翻开还在）。

## 短期记忆的三个难题和做法
1. **关掉程序就没了** → 存档：每说完一轮就把对话存成文件，下次读回来接着聊
2. **越聊越长** → 压缩：让模型把旧对话**总结**成一份"交接笔记"，替换掉原文，只保留最近几轮原文
   （就像把一整本课堂笔记，浓缩成一页复习提纲）
3. **实在太长又总结失败** → 兜底：直接丢掉最早的几轮

## 长期记忆的两种来源
- **Agent 自己记的**：上课时发现你的特点（怕长代码、喜欢做饭的比喻），自己记下来。
  好的记忆要能**新增、修改、删除**：情况变了要更新，重复的要合并，不然越记越乱。
- **你亲手写的**：一份说明文件，写下你的要求，Agent 每次开始前都读一遍，只读不改。
  Claude Code 的 `CLAUDE.md` 就是这个思路。

## 看看本项目
- **长期记忆**：`~/.agent-tutor/progress.json`。导师用 `remember` 新增、`update_memory` 修改、`forget` 删除。
  输入 `/memory` 就能看到导师记住了你什么。代码在 `src/memory.ts`。
- **说明文件**：`TUTOR.md`。写在 `~/.agent-tutor/` 里对所有目录生效，写在练习目录里只对这个目录生效。
- **存档与恢复**：每轮自动存到 `~/.agent-tutor/sessions/`。`agent-tutor --continue` 接着上次聊，`/resume` 挑一个历史对话。
  代码在 `src/session.ts`。
- **压缩**：对话太长时自动压缩，也可以手动输入 `/compact`。代码在 `src/agent.ts` 的 `compactHistory`。

## 动手练习
1. 新建 `~/.agent-tutor/TUTOR.md`，写一句你希望导师怎么教你，比如"每讲完一个知识点，先让我用自己的话复述一遍"
2. 输入 `/clear` 开始新对话（新对话才会读到新的 TUTOR.md），看导师有没有照做
3. 输入 `/memory`，看看导师记住了你哪些事

## 进阶：Skills——需要时才翻开的说明书
System Prompt 每一轮都要发给模型，写得越长越贵、越容易让模型分心。那些"偶尔才用一次"的做事方法怎么办？
答案是 **Skills**（技能）：把每套方法写成一份说明书，平时模型**只看得到名字和一句话说明**，用得上时才去读全文。
这叫**渐进式披露**——就像书架上的书，平时只看书脊上的书名，需要时才拿下来翻。
- 本项目自带两个技能：`study-plan`（定学习计划）、`explain-code`（逐段给小白讲代码），输入 `/skills` 查看
- 导师觉得用得上时会调用 `use_skill` 读取说明书；你也可以直接输入 `/study-plan 每周学两次` 让它照着做
- 自己写一个：在 `~/.agent-tutor/skills/技能名/SKILL.md` 里写好名字、说明和步骤，格式和 Claude Code 的 Skills 一样

## 小测验
问：关掉程序后用 `agent-tutor --continue` 重新打开，导师还记得刚才聊天的原话吗？不加 `--continue` 呢？
答：加了 `--continue` 会读回存档，记得原话（太长的部分可能已被压缩成摘要）；不加就是新对话，不记得原话，
但仍然记得你的水平、进度和特点，因为它们存在长期记忆 progress.json 里。
