# 第 2 课：Prompt 怎么写

## 核心概念
- Prompt 就是你给模型的指令。写得越清楚，结果越好。
- 好 Prompt 的四要素：**角色**（你是谁）、**任务**（做什么）、**要求**（格式、长度、风格）、**示例**（给个样例）。
- System Prompt：放在最前面、用户看不到的"人设和规则"，决定 Agent 的性格和行为。

## 对比
- 差：「写个介绍」
- 好：「你是科技博主。用 100 字以内、小学生能懂的语言，介绍什么是 AI Agent，结尾举一个生活中的例子。」

## 小测验
问：把"帮我总结这篇文章"改写成一个更好的 Prompt。
参考：至少要包含字数/格式要求，比如"用 3 个要点总结，每点不超过 20 字"。
